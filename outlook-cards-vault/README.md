## تسجيل الدخول وإدارة المستخدمين
- الدخول باسم مستخدم وكلمة مرور فقط. لا يوجد رقم هوية أو جوال أو SMS في واجهة الدخول.
- لا يوجد تسجيل ذاتي للمستخدمين.
- افتح الصفحة أول مرة، ثم استخدم قسم "تهيئة المدير الأول" وأدخل اسم المدير واسم المستخدم وكلمة المرور ومفتاح التهيئة الخاص الذي تم تسليمه لك في المحادثة.
- تهيئة المدير متاحة مرة واحدة فقط. بعد نجاحها يُستهلك المفتاح ويُغلق مسار إعداد المدير.
- بعد تسجيل الدخول بصفتك مديرًا، أضف المستخدمين من لوحة المدير.
- اسم المستخدم من 3 إلى 30 حرفًا: أحرف إنجليزية وأرقام والنقطة والشرطة والشرطة السفلية.
- كلمة المرور لا تقل عن 6 أحرف. سلّمها لكل مستخدم بطريقة آمنة.

## البنية
- Supabase project: `outlook-account-vault`
- URL: `https://pheqddihzwnxvgsithus.supabase.co`
- الجداول `profiles` و`cards` محمية بسياسات RLS.
- Edge Function `vault-admin-bootstrap` يهيئ المدير الأول بمفتاح سري أحادي الاستخدام محفوظ بصيغة hash داخل مخطط خاص.
- Edge Function `vault-admin-create-user` يتحقق من الجلسة والدور في جهة الخادم قبل إنشاء مستخدم.
- لا توجد مفاتيح service_role أو secret في واجهة الموقع.
- تُشفّر بيانات البطاقة في المتصفح باستخدام AES-GCM، ويشتق مفتاحها من عبارة حماية منفصلة بواسطة PBKDF2.

## أمان
- عبارة حماية الخزنة منفصلة عن كلمة مرور تسجيل الدخول. نسيانها يمنع فك تشفير البطاقات.
- المدير يرى أسماء المستخدمين وأدوارهم، ولا يستطيع فك تشفير محتوى البطاقات.
- لا تشارك مفتاح تهيئة المدير أو عبارة الخزنة أو النسخ الاحتياطية.
- اختبر مستخدمين تجريبيين قبل حفظ بيانات حقيقية.
