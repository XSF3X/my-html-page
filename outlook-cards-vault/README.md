## تسجيل الدخول وإدارة المستخدمين
- الدخول باسم مستخدم وكلمة مرور فقط؛ لا يوجد رقم هوية أو جوال أو SMS في واجهة الدخول.
- لا يوجد تسجيل ذاتي للمستخدمين.
- افتح الصفحة لأول مرة واختر "تهيئة المدير الأول". هذه العملية متاحة مرة واحدة فقط، ثم تُقفل في قاعدة البيانات.
- بعد تسجيل دخولك كمدير، أضف المستخدمين من لوحة المدير باسم مستخدم وكلمة مرور.
- اسم المستخدم من 3 إلى 30 حرفًا، ويتكون من حروف إنجليزية صغيرة وأرقام والنقاط والشرطة السفلية أو الشرطة العادية.
- كلمة المرور لا تقل عن 12 حرفًا. سلّمها لكل مستخدم بشكل آمن.

## البنية
- Supabase project: `outlook-account-vault`
- URL: `https://pheqddihzwnxvgsithus.supabase.co`
- الجداول `profiles` و`cards` محمية بسياسات RLS.
- Edge Function `vault-admin-bootstrap` يهيئ المدير الأول مرة واحدة فقط.
- Edge Function `vault-admin-create-user` يتحقق من الجلسة والدور من جهة الخادم قبل إنشاء مستخدم.
- لا توجد مفاتيح service_role أو secret في واجهة الموقع.
- تُشفّر بيانات البطاقة في المتصفح باستخدام AES-GCM، ويشتق مفتاحها من عبارة حماية منفصلة بواسطة PBKDF2.

## نشر GitHub Pages
المشروع يعمل عبر سير عمل `.github/workflows/deploy-pages.yml` الذي ينشر المستودع بعد كل تحديث إلى `main`.

## ملاحظات أمان
- عبارة حماية الخزنة ليست كلمة مرور تسجيل الدخول. احتفظ بها في مكان آمن؛ نسيانها يمنع فك تشفير بطاقاتك.
- المدير يرى أسماء المستخدمين وأدوارهم فقط ولا يستطيع فك تشفير البطاقات.
- لا تُشارك نسخة احتياطية مشفرة إلا مع من تثق به.
- اختبر مستخدمين تجريبيين قبل حفظ بيانات حقيقية، وتأكد أن كل مستخدم لا يرى إلا بطاقاته.
